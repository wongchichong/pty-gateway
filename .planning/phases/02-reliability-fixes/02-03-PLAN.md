# PLAN: Add Timer Error Recovery

## Objective
Stop auto-refresh timers after 3 consecutive errors to prevent zombie processes.

## Tasks

### Task 1: Add error counter
**File**: `src/router.ts` in auto-refresh interval

```typescript
let errorCount = 0;
const interval = setInterval(async () => {
  try {
    // ... existing code
    errorCount = 0;  // Reset on success
  } catch (err) {
    console.error(`  ❌ Auto-refresh error: ${err}`);
    errorCount++;
    if (errorCount >= 3) {
      console.error(`  🛑 Stopping auto-refresh after 3 errors`);
      this.stopAutoRefresh(sessionKey);
    }
  }
}, 10000);
```

## Success Criteria
- [ ] Error counter tracks failures
- [ ] Timer stops after 3 errors
- [ ] Logged appropriately
