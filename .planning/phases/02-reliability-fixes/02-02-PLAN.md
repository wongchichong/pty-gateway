# PLAN: Add Memory Cleanup

## Objective
Clear `lastMessages` and `editCounters` maps when sessions end to prevent memory leaks.

## Tasks

### Task 1: Add cleanup in stopAutoRefresh()
**File**: `src/router.ts`

```typescript
private stopAutoRefresh(sessionKey: string) {
  const interval = this.refreshIntervals.get(sessionKey);
  if (interval) {
    clearInterval(interval);
    this.refreshIntervals.delete(sessionKey);
    this.editCounters.delete(sessionKey);
    this.lastMessages.delete(sessionKey);  // ADD THIS
    console.log(`[AutoRefresh] Stopped and cleaned up: ${sessionKey}`);
  }
}
```

## Success Criteria
- [ ] Maps cleared on session end
- [ ] Memory stable over time
