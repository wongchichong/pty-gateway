# PLAN: Use Async FS Operations

## Objective
Replace sync file operations with async to avoid blocking event loop.

## Tasks

### Task 1: Replace writeFileSync
**File**: `src/router.ts`

```typescript
// BEFORE
writeFileSync(this.idMapFile, JSON.stringify(map, null, 2));

// AFTER
import { writeFile } from "fs/promises";
await writeFile(this.idMapFile, JSON.stringify(map, null, 2));
```

### Task 2: Replace readFileSync
```typescript
// BEFORE
const data = readFileSync(this.idMapFile, "utf8");

// AFTER
import { readFile } from "fs/promises";
const data = await readFile(this.idMapFile, "utf8");
```

## Success Criteria
- [ ] All fs operations async
- [ ] Error handling added
- [ ] Non-blocking verified
