# PLAN: Remove Hardcoded Token from pty-gateway.service

## Objective

Remove the hardcoded Telegram bot token from the systemd service file and use environment variables instead.

## Context

**Problem**: The Telegram bot token is hardcoded in `pty-gateway.service` at lines 11-12:
```ini
Environment="TELEGRAM_BOT_TOKEN=8520957421:AAGBrVEnuGDeFAfAE1GRyJ_-0rJSTL9FtKU"
Environment="TELEGRAM_ALLOWED_USERS=255433743"
```

This is a critical security vulnerability - the service file is typically committed to version control.

**Solution**: Use systemd's environment file feature or drop-in configuration.

## Tasks

### Task 1: Update pty-gateway.service

**File**: `pty-gateway.service`

Replace hardcoded values with environment file reference:

```ini
# BEFORE
Environment="TELEGRAM_BOT_TOKEN=8520957421:AAGBrVEnuGDeFAfAE1GRyJ_-0rJSTL9FtKU"
Environment="TELEGRAM_ALLOWED_USERS=255433743"

# AFTER
EnvironmentFile=/etc/pty-gateway/config.env
```

**Complete updated file**:
```ini
[Unit]
Description=PTY Gateway Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/projects/pty-gateway
EnvironmentFile=/etc/pty-gateway/config.env

# Auto-restart on failure
Restart=always
RestartSec=10

# Start limit (prevent restart loops)
StartLimitIntervalSec=60
StartLimitBurst=5

# Logging
StandardOutput=journal
StandardError=journal
SyslogIdentifier=pty-gateway

# Executable
ExecStart=/usr/bin/pnpm exec tsx src/index.ts

# Graceful shutdown
KillMode=mixed
KillSignal=SIGTERM
TimeoutStopSec=30

[Install]
WantedBy=multi-user.target
```

### Task 2: Create Environment File Template

**File**: `config.env.example` (new file)

Create a template file showing the required environment variables:

```bash
# PTY Gateway Configuration
# Copy this file to /etc/pty-gateway/config.env and fill in values

# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=your-bot-token-here
TELEGRAM_ALLOWED_USERS=your-user-id-here

# PTY Service
PTY_URL=http://localhost:3000

# Optional: Additional allowed users (comma-separated)
# TELEGRAM_ALLOWED_CHATS=
```

### Task 3: Update OPERATIONS.md

**File**: `OPERATIONS.md`

Add systemd setup instructions to the Environment Variables section:

```markdown
### Option 3: Systemd service

**Setup:**

1. Create configuration directory:
```bash
sudo mkdir -p /etc/pty-gateway
```

2. Create environment file:
```bash
sudo cp config.env.example /etc/pty-gateway/config.env
sudo chmod 600 /etc/pty-gateway/config.env
```

3. Edit with your tokens:
```bash
sudo nano /etc/pty-gateway/config.env
```

4. Install and start service:
```bash
sudo cp pty-gateway.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable pty-gateway
sudo systemctl start pty-gateway
```

5. Verify:
```bash
sudo systemctl status pty-gateway
sudo journalctl -u pty-gateway -f
```

**Security notes:**
- The config file has restricted permissions (600 - owner read/write only)
- The file is NOT in the git repository
- Rotate tokens if the file is accidentally exposed
```

**File**: `.gitignore`

Add environment file to gitignore:

## Security Notes

- The environment file `/etc/pty-gateway/config.env` should have permissions `600` (owner read/write only)
- Never commit `config.env` to git
- Rotate the Telegram bot token after removing hardcoded values (old token was exposed in git history)
