# PLAN: Remove Hardcoded Token from ecosystem.config.js

## Objective

Remove the hardcoded Telegram bot token from `ecosystem.config.js` and replace it with environment variable reference. Add validation to ensure the token is provided at startup.

## Context

**Problem**: The Telegram bot token is hardcoded in `ecosystem.config.js` at line 13:
```javascript
TELEGRAM_BOT_TOKEN: "8520957421:AAGBrVEnuGDeFAfAE1GRyJ_-0rJSTL9FtKU"
```

This is a critical security vulnerability - anyone with repository access can hijack the bot.

**Solution**: Use environment variables with validation on startup.

## Tasks

### Task 1: Update ecosystem.config.js

**File**: `ecosystem.config.js`

Replace hardcoded token with environment variable:

```javascript
// BEFORE
TELEGRAM_BOT_TOKEN: "8520957421:AAGBrVEnuGDeFAfAE1GRyJ_-0rJSTL9FtKU"

// AFTER
TELEGRAM_BOT_TOKEN: process.env.TELEGRAM_BOT_TOKEN
```

**Changes**:
- Line 13: Replace hardcoded value with `process.env.TELEGRAM_BOT_TOKEN`
- Line 47: Same change for monitor app config

### Task 2: Add Environment Variable Validation

**File**: `src/index.ts`

Add validation at startup to ensure required environment variables are set:

```typescript
// Add after imports, before main logic
function validateEnvironment(): void {
  const required = [
    'TELEGRAM_BOT_TOKEN',
  ];

  const missing = required.filter(key => !process.env[key]);

  if (missing.length > 0) {
    console.error('❌ Missing required environment variables:');
    missing.forEach(key => console.error(`  - ${key}`));
    console.error('\nSet them via:');
    console.error('  export TELEGRAM_BOT_TOKEN="your-token"');
    console.error('  or');
    console.error('  TELEGRAM_BOT_TOKEN="your-token" pm2 start ecosystem.config.js');
    process.exit(1);
  }
}

// Call at start of main()
validateEnvironment();
```

**Location**: After imports, before the main execution logic.

### Task 3: Update OPERATIONS.md

**File**: `OPERATIONS.md`

Add new section after "Environment Variables" heading (around line 238):

```markdown
## Environment Variables

**Required:**
- `TELEGRAM_BOT_TOKEN` — Telegram bot token from @BotFather
- `TELEGRAM_ALLOWED_USERS` — Comma-separated user IDs allowed to use the bot

**Setup:**

### Option 1: Export in shell
```bash
export TELEGRAM_BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
export TELEGRAM_ALLOWED_USERS="255433743"
pm2 start ecosystem.config.js
```

### Option 2: PM2 environment file
Create `.env` file (DO NOT commit to git):
```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_ALLOWED_USERS=255433743
```

Update ecosystem.config.js to load from `.env`:
```javascript
env_file: ".env"
```

### Option 3: Systemd service
```bash
sudo systemctl edit pty-gateway
```

Add:
```ini
[Service]
Environment="TELEGRAM_BOT_TOKEN=your-token-here"
Environment="TELEGRAM_ALLOWED_USERS=255433743"
```

**Security Best Practices:**
- ✅ Never commit tokens to git
- ✅ Use `.gitignore` to exclude `.env` files
- ✅ Rotate tokens if accidentally exposed
- ✅ Use different tokens for dev/staging/production
```
