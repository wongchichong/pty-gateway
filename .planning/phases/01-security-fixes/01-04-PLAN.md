# PLAN: Add Command Input Validation

## Objective

Implement command whitelist validation to prevent users from executing dangerous or unauthorized commands through the PTY gateway.

## Context

**Problem**: Users can send any command to the PTY instance:
```typescript
await this.pty.send(session.instanceId, msg.text + "\n");  // Direct send
```

This allows:
- `rm -rf /` — destructive commands
- `sudo` — privilege escalation
- `curl | bash` — arbitrary code execution
- `cat /etc/passwd` — sensitive file access

**Solution**: Whitelist safe commands and validate before execution.

### Task 2: Create Validation Function

**File**: `src/router.ts`

Add command validation function:

```typescript
function validateCommand(command: string, safeCommands: string[]): { valid: boolean; reason?: string } {
  // Extract the base command (first word)
  const baseCommand = command.trim().split(/\s+/)[0];

  // Check if command is blocked
  for (const blocked of BLOCKED_COMMANDS) {
    if (blocked.includes(".*")) {
      // Regex pattern
      if (new RegExp(blocked).test(command)) {
        return { valid: false, reason: `Command '${baseCommand}' is blocked for security reasons` };
      }
    } else if (baseCommand === blocked) {
      return { valid: false, reason: `Command '${baseCommand}' is blocked for security reasons` };
    }
  }

  // Check if command is in safe list
  if (!safeCommands.includes(baseCommand)) {
    return {
      valid: false,
      reason: `Command '${baseCommand}' is not in the allowed list. Allowed commands: ${safeCommands.slice(0, 10).join(", ")}...`
    };
  }

  return { valid: true };
}
```

### Task 3: Integrate Validation into Message Handler

**File**: `src/router.ts`

Add validation in `handleChannelMessage`:

```typescript
async handleChannelMessage(msg: ChannelMessage): Promise<void> {
  console.log(`[${msg.channel}] 📨 Message received: "${msg.text}"`);

  // Rate limiting check (from Plan 01-03)
  const { allowed, remaining } = checkRateLimit(msg.channel, msg.userId);
  if (!allowed) {
    const channel = this.channels.get(msg.channel);
    if (channel) {
      await channel.sendMessage(msg.chatId, getRateLimitMessage(msg.channel));
    }
    console.log(`[${msg.channel}] ⚠️ Rate limit exceeded for user ${msg.userId}`);
    return;
  }

  console.log(`[${msg.channel}] ✅ Rate limit check passed (${remaining} remaining)`);

  // Parse command
  const text = msg.text.trim();

  // Check if it's a PTY command (not a gateway command like /start, /list, etc.)
  const isGatewayCommand = text.startsWith("/");
  const hasActiveSession = this.sessions.has(`${msg.channel}:${msg.chatId}`);

  if (hasActiveSession && !isGatewayCommand) {
    // This is a command to send to PTY - validate it
    const safeCommands = this.getSafeCommands();
    const validation = validateCommand(text, safeCommands);

    if (!validation.valid) {
      const channel = this.channels.get(msg.channel);
      if (channel) {
        await channel.sendMessage(msg.chatId, `❌ ${validation.reason}`);
      }
      console.log(`[${msg.channel}] ⚠️ Command blocked: ${text}`);
      return;
    }

    console.log(`[${msg.channel}] ✅ Command validated: ${text}`);
  }

  // ... rest of existing logic
}

// Add method to get safe commands from config or defaults
private getSafeCommands(): string[] {
  const envCommands = process.env.ALLOWED_COMMANDS;
  if (envCommands) {
    return envCommands.split(",").map(c => c.trim());
  }
  return DEFAULT_SAFE_COMMANDS;
}
```

## Security Considerations

**Whitelist Limitations:**
- Users can still read sensitive files with `cat /etc/passwd`
- Allowed commands like `vim` can execute shell commands
- This is defense-in-depth, not a complete security solution

**Additional Hardening (Future):**
- Chroot/jail PTY processes
- Run as unprivileged user
- File system permissions
- Audit logging
- SELinux/AppArmor profiles

## Rollback

If issues arise:
```bash
# Disable validation by allowing all commands
export ALLOWED_COMMANDS="*"  # Or remove validation code
```

## Performance Impact

- **Latency**: < 1ms per command for validation
- **Memory**: Minimal - whitelist is a small array
- **CPU**: Negligible - simple string comparison
